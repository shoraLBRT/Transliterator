# Правила репозитория

## Сообщения коммитов

- Сообщение коммита (заголовок и тело) пишется **на английском языке**.
- **В заголовке кириллицы нет совсем**, даже в кавычках: проверка заголовка PR
  (`pr-title / check`) и hook Claude его не пропустят. PR вливается squash'ем, и
  заголовок PR становится заголовком коммита — правило относится к нему тоже.
- В **теле** русский допустим только внутри английского текста — как литерал или
  цитата, когда без него не обойтись: название правила таджвида, строка из
  корпуса, ожидаемый вывод транслитерации. Такие вставки берутся в кавычки или
  обратные апострофы.
- Формат заголовка прежний — Conventional Commits с кодом пункта плана в скобках:
  `type(scope): summary (B3)`.

Пример:

```
fix(parser): handle wasl in article with shadda on lam (B1)

Output for "бисмилля" no longer drops the wasl.
```
